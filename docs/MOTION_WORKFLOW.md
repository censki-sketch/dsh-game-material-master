# DSH 白模动作流程

图片「流转到 → 八方向图生成」支持选择目标项目与填入位置：「角色细节参考图」或「八方向外观图（四列两行）」，只替换对应图片。上传卡片和动作卡片未选择时加号与灰色文字整体居中；选择后文字覆盖底部，图片及动作预览延伸到文字下方。图片生成的参考缩略图也采用图片与底部编号叠放的方形卡片。素材面板将历史参考图放在使用它的轮次中并标明「参考图」，重复用于不同轮次时分别保留引用。更新此功能后需完全退出 DSH（包括托盘）再打开。

视频设置可从生成页面右上角的「设置 → 生成视频」打开，也可进入 DSH 的「设置 → 游戏素材大师 → 生成视频 → MiniMax（图生视频）」。填写 Key 和接口地址后，可点「使用白模推荐参数」选择 MiniMax-H3-Lite、4 秒、480P；保存和选参数不会生成视频。

设置页的生图、MiniMax、音乐和音效 API Key 输入框提供眼睛图标，点击后查看已保存的原Key，再次点击隐藏；有未保存输入时仅切换该草稿的可见性。保存后回显固定掩码，聚焦输入框可填写替换值，留空保持原值；默认隐藏明文，离开该输入区域、切换配置或离开窗口后收起明文；查看不填入编辑草稿，也不保存、清除或调用生成接口。常规配置读取仍脱敏，原Key仅通过设置页的单项读取接口返回，该接口不对模型工具开放。更新此功能后需完全退出DSH（包括托盘）再打开，以加载新增宿主接口。

原有八方向流程的项目操作收在列表项目右侧的「⋯」菜单中：重命名、复制 ID、删除项目。菜单只操作对应项目，删除前仍需确认；顶部保留刷新列表、新建项目与设置。

图片生成沿用此布局：新建任务位于右上角设置旁，左侧各任务的「⋯」菜单提供重命名、复制 ID 和删除任务，删除使用自定义确认弹窗。

各模块、设置、模板与排序的成功、失败和操作反馈统一显示为顶部居中的浮层消息弹窗，不占页面高度、不抢输入焦点。同一时刻只保留一条最新消息；成功提示4秒、一般提示6秒后自动收起，悬停或键盘聚焦时暂停，错误提示保留到手动关闭；支持关闭图标和Esc，不影响已有弹窗的Esc关闭。静态配置状态与任务结果仍显示在对应内容中。

提示词框右下角按「透明背景 → 优化提示词」排列，`@参考图片`留在左下角；窄屏可自动换行，保持右侧操作组对齐。

参考素材上传区使用带加号的可点击虚线框，点击即可选择文件，也可直接拖入；上传期间禁用重复选择和拖入，不再单列「选择文件」按钮。

图片参考图每张一行，显示缩略图、`@图片N` 编号和文件名，窄屏也保持列表。单击缩略图或名称可打开原图预览，支持关闭按钮、Esc、点击遮罩关闭并恢复焦点；移除为独立按钮，不触发预览或生成。

参考图「移除」默认隐藏，鼠标移到对应行或键盘聚焦该行时显示，预留按钮位置以免文件名跳动；无悬停能力的触屏保持可见。

图片结果卡片将「⋯」更多入口置于状态徽章右侧，通过/取消通过、下载原图、下载透明PNG、重新生成和删除都在该图片的菜单中。菜单根据文件与任务状态显示或禁用操作，上传结果不提供重新生成；支持方向键、Home/End、Esc和点击外部收起，定位始终留在窗口内。展开菜单不会生成或删除图片。

图片生成的提示词与参考图区左右排列，无分割线，各区标题不带数字编号：左侧编辑提示词，右侧选择参考图；标题后的圆形感叹号与文字垂直居中对齐，可悬停、聚焦或点击查看描述，Esc 或点外部收起。生成按钮与审核模式位于右侧结果卡片顶部同一行，审核下拉和基础提示词选择器使用主题化的原生可定制选单，旧浏览器保留标准下拉。审核支持自动、人工与未设置切换，保存失败弹窗说明；清除模式通过null写入宿主并删除已有值。此修复涉及宿主接口，需完全退出DSH（含托盘）再打开。模型、尺寸来源、任务/全局尺寸与生成张数收在提示词卡片下方的「高级设置」；它和「高级抠像与已有图片」共用一张卡片，默认折叠且独立展开。结果区在工作台最右侧，单击结果图可用原生dialog预览，优先显示透明PNG，否则显示原图；支持Esc、关闭按钮、遮罩关闭与焦点恢复。内容区域较窄时自动改为上下排列，操作行可换行。

主提示词输入框内部右下角的「优化提示词」使用彩色魔棒图标，撤销按钮也位于框内；操作栏和文本分区，不遮挡输入内容。打开或重新打开弹窗**不发起请求**，即使主提示词为空也可打开；左侧「原提示词」可独立编辑，点击弹窗内的「优化提示词」才读取DSH默认模型并调用，沿用已有登录凭据与用量规则，无需额外填写 API Key。只有点击「采用优化结果」才保存并替换生成页的主提示词，也可撤销；基础提示词仅作为约束发送，保持原文。任务、原提示词、生成页草稿、模板或参考图变化后，旧结果不能覆盖新草稿。

在生成页「主提示词」或优化弹窗「原提示词」中输入 `@`，或点「引用图片」，可从当前任务已上传的参考图中选择，显示缩略图与文件名，插入 `@图片1`、`@图片2` 等标签；仅在光标紧挨着 `@` 时自动弹出，继续输入后收起；完整引用和后续文字不会触发菜单。支持上下方向键、Enter选择和Esc收起。主提示词或附加模板中有明确引用时，仅发送指定的图片；没有引用时使用全部已上传参考图。优化和生图共用此规则，按上传顺序发送并保留原编号，最终生图请求写明附图与标签的对应关系。宿主核对任务归属、引用编号与文件列表，经过DSH附件服务校验后作为真正的图片内容发送。图片请求使用 `llm.prepareCall` 固定模型能力与调用路由；模型未声明图片输入能力、旧DSH缺少附件服务、引用已失效或超出图片限制时，在提交模型前拒绝，并提示更换支持图片的默认模型或移除参考图。优化结果若改变图片编号则不采用，不自动重试。PNG/JPEG/WebP可用于引用；BMP需先转换格式。

优化器适用于角色、道具、建筑和场景等素材，只整理用户意图，不默认补充角色、像素画或八方向要求。「不使用模板」时不追加隐藏美术模板。每次优化在同一次模型调用中返回提示词和「需求核对」，列出目标、必须修改、明确保留及各图的参考用途；需求模糊时显示待补充问题，不能采用空结果，补充原提示词后再手动优化。优化使用当前草稿的模板与透明背景设置，背景规则只约束背景，不要求主体保持原样。仅在优化提示词弹窗中展开「查看最终生图请求」（未优化或结果过期时预览原文，优化后预览结果），免费查看完整提示词和参与的参考图；此预览不调用模型，也不保存草稿，实际生成仍使用点击生成时的最新设置。模板、背景或参考图改变后，旧优化结果不能直接采用。

有效的 `@图片N` 引用在主提示词和原提示词输入框中显示主题色文字和浅色背景高亮；两处共用同一输入组件，保留普通文本编辑、选择、复制和中文输入，滚动或调整输入框大小时高亮同步位置。主提示词选择引用后仍保留焦点，离开输入框时沿用原有保存逻辑；换任务后重置选择菜单。

有效图片引用按整体删除：光标位于引用中或紧邻引用时按 Backspace / Delete，整块删除；选区只覆盖引用的一部分时也会删除完整引用，跨多个引用时一起删除。输入法组词期间不拦截按键，无效编号和普通文字仍按正常文本编辑。

提示词框内提供「透明背景」开关，默认关闭，按任务保存。开启后无需填写抠像参数；发送生图请求时自动追加明确的均匀纯色背景要求，覆盖提示词、模板或参考图中冲突的背景描述，禁止投影、光晕和棋盘格；内置模板的默认白背景要求从本次请求中去掉，主体配色和保存的输入原文不改。生成后使用提交时固定的同一背景色与参数在本地抠成透明 PNG，不额外调用模型。默认采用任务或全局已有底色；高级参数、重新抠像和已有图片上传收在默认折叠的「高级抠像与已有图片」中。关闭后不追加此背景要求，也不自动抠像。宿主生图逻辑已更新，需完全退出DSH（包括托盘）后重新打开。

插件直接调用DSH模型，不开新对话，不提供任何工具，也不提交生图或视频任务。失败不自动重试，调用前在本机记录尝试状态；记录不含提示词正文或图片数据。验证使用模拟模型与合成图片，不使用真实账户。使用新功能前需从托盘完全退出 DSH 后重新启动，以加载宿主方法和图片引用字段；旧宿主未声明图片引用协议支持时，客户端会拒绝带图提交，避免字段被旧wire丢弃后误作纯文字请求。

图片生成提供「角色素材 / 像素角色 / 八方向外观」基础模板，在「优化提示词」弹窗左侧原提示词输入框底部使用下拉选择器选择模板（含自定义模板和「不使用模板」），只读标记、查看内容与管理入口一并嵌入框内，标题、选择器、只读标记与管理按钮保持一行，不遮挡输入文字，生成页不再显示此区域，基础提示词**只读**；保留「查看模板内容」展开全文，显示当前任务实际使用的提示词，不提供行内编辑。当前模板已更新时提供「同步更新」按钮，不自动替换任务正文；无法匹配模板的旧内容显示为「已保存的提示词」。点击「管理模板」直达「设置 → 提示词模板 → 提示词模板管理」，可新增、重命名、编辑中英内容。内置模板**不能删除**，可编辑或恢复默认内容；只有自定义模板提供删除按钮，保存接口也拒绝移除内置模板。旧配置缺失的内置模板会自动补回，保留其余编辑和自定义模板。集中点击「保存模板」后写入本机 `config.json` 的 `imagePromptTemplates`，不调用任何生成接口。最多24个模板，每种语言的名称最多60字、正文最多6000字，未填写的语言使用另一语言内容；非法内容保存时拒绝而非截断。

切换基础模板仅更新页面草稿，不逐次调用保存，也不显示「正在保存」或锁住模板按钮。当前浏览器页面内切换任务、进入设置再返回时按任务保留选择，刷新页面后恢复宿主已保存的内容。点击「生成」或「重新生成」时，才将主描述、最终模板选择与预览正文一次性保存；保存失败不提交生成请求。文字优化直接使用当前选中的正文，不必先保存模板选择。

若旧配置原有24个自定义模板，自动补回内置模板后会暂时超过上限，读取时保留全部内容；删除多余自定义模板后即可保存。

任务在 `suffix` 中保存所选模板的正文，并记录 `promptTemplateId` / `promptTemplateLang`。同时传 `suffix` 与 `promptTemplate` 时，正文作为明确的模板快照保存，保证预览与提交一致，即使此时全局模板已更新或自定义模板已删除。修改模板或删除自定义模板不自动改写已有任务；返回生成页会提示模板更新，点击对应模板同步后才采用新内容。可选择「不使用模板」清空。旧任务的自定义附加提示词保留为只读内容，选择模板替换前有行内确认。界面新建任务默认使用角色素材模板；通用 API 调用不带 `promptTemplate` 时仍保留空附加提示词，避免影响地图等其他素材用途。

内置模板强调完整全身、干净纯白背景、清晰色块、无投影暗角光晕，并以用户明确要求优先于模板默认值和参考图外观。Q版不会自动转为像素风；像素模板才加入有限调色板和硬边要求。八方向模板使用四列两行（北、东北、东、东南 / 南、西南、西、西北），仅生成方向外观图，不等于动作序列帧。文字优化同时收到角色模板基础指导和当前任务的只读约束，不会虚构自己看过参考图。模板无法保证模型严格执行，实际效果仍需人工验收。宿主修改后需完全退出DSH（包括托盘）再打开。

顶部功能入口使用单行文字选项卡，选中项以下划线标识，窄窗口可横向滚动；支持左右方向键及 Home / End 切换。隐藏功能提示位于标题下方。悬停或键盘聚焦选项卡时显示主题配色的圆角说明浮层，自动避开窗口边缘；点击、滚动或按 Esc 收起。

进入设置后，顶部「设置」按钮改为「返回」，回到进入设置前的功能；该功能被隐藏时回到第一个可见功能。内容区不再重复显示插件标题和顶部配置说明。设置分类使用横向文字选项卡，选中项显示下划线，支持方向键及Home/End，窄窗口横向滚动。生图、生视频、画面与抠像、音乐、功能与数据内部改为左侧配置组选项卡、右侧当前配置，避免多个配置卡上下堆叠；支持上下方向键及Home/End，切换只隐藏表单，保留输入草稿，不切换实际后端，也不触发测试或生成请求。当前使用的后端在左侧以圆点标记。提示词模板的「中文 / English / 保存模板 / 放弃修改 / 恢复或删除」在编辑区顶部排成一行，语言切换位于最左侧，不显示「已保存」状态文字；窄窗口下工具栏可横向滚动，无需滚到正文下方保存。自定义模板删除使用确认弹窗，展示模板名称，默认聚焦取消，支持Esc取消；确认仅删除本地草稿，仍需点击「保存模板」写入配置，已有任务的提示词保留。

点击侧栏进入工作台时恢复浏览器缓存中的上次功能；没有缓存、记录无效或该功能已隐藏时，打开当前排序后的第一个可见功能。配置加载完成后才确定默认页。设置页不覆盖功能记录，快捷菜单和任务回链仍优先打开指定功能。

项目删除使用与页面主题一致的确认弹窗，展示项目名称与不可撤销提示；默认焦点在取消按钮。删除失败会在弹窗内显示原因，处理中禁止重复提交。

「设置 → 功能与数据 → 功能管理」支持拖动每行左侧的六点手柄排序，在行内、两行之间的插入线或列表首尾放下后自动保存，并同步到顶部功能栏和侧栏快捷菜单。手柄获得焦点后也可用上下方向键调整。隐藏功能保留其排序位置，可用「恢复默认顺序」重置排列。更新此功能后需重启 DSH 以加载宿主配置字段。

付费视频总开关 `allowPaidVideoGeneration` 默认关闭，旧配置缺少此字段也会锁定。只有用户在界面手动开启后才能提交 MiniMax / ToAPIs 新任务；每次提交仍需确认模型、时长、分辨率和视频段数。白模流程一次为 1 段输出加 4 秒参考输入，原有八方向流程可能为 8 段独立视频。界面不查询余额或实时单价，实际费用以服务商为准。关锁不妨碍查询下载已有任务、本地准备、导入、抽帧或 ComfyUI。

对话工具不能代为开启开关。`runTurnVideo`、`runVideos`、`runSequenceVideo` 及白模视频提交均需本次授权后传 `confirmed:true`。验证只使用本机假 API，不使用真实余额。

这是「八方向图生成」模块内的新默认入口，保留 DSH 插件结构与原有八方向流程。日常操作在插件内完成，不需要 Codex 或聊天 agent 参与。

## 从公开 GitHub 安装

适用于 **DeepSeek Harness（DSH）** 的插件系统。DSH 的 `plugin` 命令将包参数传给 pnpm，因此支持 GitHub 源码和 HTTP 安装包。普通 DeepSeek 网页聊天没有这套 DSH 插件加载器。

推荐使用带构建产物的版本包；无需安装 Python 或手动编译。桌面版必须先启动过一次以初始化 `desktop` profile，之后从托盘**完全退出 DSH**再执行安装（仅关闭窗口可能仍在后台运行）：

```powershell
dsh plugin --profile desktop add "https://github.com/censki-sketch/dsh-game-material-master/releases/download/v0.12.0-motion.1/dsh-game-material-master-0.12.0-motion.1.tgz"
```

从同一版本的源码安装：

```powershell
dsh plugin --profile desktop add "github:censki-sketch/dsh-game-material-master#v0.12.0-motion.1"
```

使用其他 profile（例如 `web`）时替换名称。已使用 DSH 自带 CLI 在独立临时 `web` profile 实测从上述公开 GitHub 安装包下载并安装成功（0.12.0-motion.1）。重新启动 DSH 后打开侧栏「游戏素材大师」。如果终端找不到 `dsh`，请先启用 DSH 的命令行入口；Windows 也可使用安装目录下 `resources/runtime/cli/bin/dsh.cmd`。这版保留原插件 ID，应替换已有安装，避免同时加载两份。GitHub 仓库为公开 MIT Fork，任何人可克隆；内置白模为 CC0，每个使用者自行配置 API Key，仓库不附带账号额度或私人角色素材。

## 操作顺序

1. **选择来源**：聊天输入区直接上传素材，每个位置最多一个文件，再次上传会替换。生成新视频时，角色细节图和四列两行八方向外观图都必传；也可在「处理配置」从已有八方向项目导入。上排：北、东北、东、东南；下排：南、西南、西、西北。生成模式不显示视频上传；切换为「解析视频」才显示必传的视频位置，并隐藏两张图片，此模式不调用视频生成服务。
2. **手动选择动作**：上传和动作选择使用同排方形卡片，宽屏 64×64、窄屏 56×56；图片和视频显示缩略预览，选中的动作直接循环播放本地预览。点击动作卡打开完整选择器；悬停或聚焦时显示逐项清除，上传卡同样提供替换和移除。新任务及新增动作槽留空，不预选动作。执行方式、动作数量、优化和模型切换保留在下方工具栏，发送按钮固定。4 秒安排 2 或 3 种动作，数量菜单不显示推荐或实验性标签。解析已有视频时不显示动作数量或动作选择，也不要求分段确认；默认整段解析，可在顶部「处理配置」调整视频范围及抽帧数量。解析按四列两行裁切，不自动识别动作。
动作选择器支持按中文名、英文原名或动作标识搜索，说明收在标题旁的感叹号内；无匹配时显示空状态。单方向与八方向同时预览可切换，八方向按四列两行排列，共用播放、暂停、帧号和重播。上传与动作卡片整排靠左，缩略图及动画在卡片内居中铺满，名称叠在底部，悬停或聚焦时可清除。滚动条仅在滚动时显示，停止后隐藏且不挤动内容。预览只读取本地模板，不调用生成模型。

3. **提示词优化、模板与生成**：生成新视频必须填写本轮提示词；空白或纯空格时按钮、快捷键与编辑器发送事件均不可提交，后台在创建轮次或调用模型前也会拒绝。解析已有视频不要求提示词。点击「优化提示词」打开与图片生成共用的优化弹窗，打开不调用模型；选择主操作栏中的 DSH 模型，再显式点击优化。优化只整理补充要求，所选动作、时间分段、4 秒时长、八方向布局、角色说明和底色作为只读约束；冲突时返回待补充问题。采用结果只更新草稿，可撤销，不生成视频。模板选择和管理位于弹窗上方；单一「提示词预览」默认收起，展开后在模板内容和最终提示词间切换。原文和结果编辑框对齐，右上角使用关闭图标。最终预览使用未保存草稿，不调用模型、不保存。图片和视频共用模板管理，按类型筛选，旧模板自动保留，内置模板可编辑或恢复，不能删除。`{{timeline}}`、`{{description}}`、`{{keyColor}}` 分别填时间线、角色说明和背景色。模板在本地独立拼接，不重复抄入优化结果。八方向外观参考图要求内容为四列两行，不强制图片宽高比；1536×1024 等原图保留原始字节，不拉伸、不裁切。本地白模视频与输出视频的画幅校验继续保留。生成前本地拼接 4 秒、24 FPS、864×480 白模参考，再经费用确认向 MiniMax 提交一次 4 秒视频请求；输出分辨率按输入栏所选型号适配为 480P 或 768P。

   动作卡片右侧增加「参考视频」方形预览入口。选齐有效且不重复的动作后自动合成，无需图片或提示词；合成中显示加载状态并禁止预览，完成后显示缩略图并允许点击查看，合成不会自动打开弹窗。空态图标、灰色文字与动作卡片对齐。`previewMotionReference({jobId,segments,keyColor})` 是仅供界面的本地接口，读取当前未保存的动作与底色，使用与 `prepare` 相同的渲染函数输出真实 4 秒 MP4 和首帧；只写入 `prepared/` 素材，不改任务 JSON、不创建聊天轮次、不调用模型。弹窗可播放、暂停、拖动进度和循环，浅深色与窄屏均适配，说明收在标题感叹号里。重复打开复用当前预览；动作、分段或底色变化后立即移除旧缩略图和播放状态并自动更新，迟到结果不能覆盖新草稿。失败时提示原因，卡片提供手动重新合成入口，不自动反复重试。解析已有视频时隐藏此入口。
4. **处理配置**：从页面顶部打开，提取序列帧、背景抠除、合成整图默认开启，可独立关闭。按起止时间与目标 FPS 自动计算每方向帧数：新任务默认 24 FPS，两秒动作为 48 帧；目标 FPS 可设为 1–60，单段最多 720 帧，超限需缩短范围或降低 FPS。旧任务缺少目标 FPS 时保留原帧数与时长，编辑该范围后才按新参数计算。还可调裁切边距、抠像颜色及边缘参数、图集单格尺寸。生成完成后按这些配置处理，视频和各处理版本留在同一轮。实际动作错位时，在该轮「视频处理」重新抽帧、抠图或合图；这些本地操作不会再次提交视频。素材、动作、模板内容、最终提示词及处理配置随提交保存，修改全局模板不改变已有轮次。

预设分段不是动作识别结果。模型可能延迟切换或生成过渡动作，例如计划 2 秒进入奔跑，实际却在 2.7 秒后才进入。该轮「视频处理」读取原视频真实帧时间轴，以从 1 开始的帧号定位；支持输入帧号、上一帧/下一帧及视频聚焦后的左右键；上方「图片选帧」为单排横向滚动，不再分页。只显示当前动作可用的完整源帧，其他动作占用的帧隐藏；可用范围由前一个动作结束、后一个动作开始限定，动作之间留出的空隙仍可调整。蓝色背景和勾表示选入起止范围，普通边框表示可用但未选入，橙色边框和圆点单独表示当前预览。点击图片只定位预览，再点击开始/结束定位图标确定范围。缩略图支持滚轮横移、触摸、左右键、Home/End 与 Enter，跳转帧号或逐帧播放时自动滚动到当前预览；宽窄屏始终保持一排。起始帧、结束帧及范围手柄按原视频帧吸附，结束帧包含选中帧；秒数仅辅助显示。29.97 FPS 和变帧率视频按实际时间戳处理，不用抽帧 FPS 猜测源帧。定位图标将当前画面设为开始或结束，播放图标仅播放该范围，范围不能越过相邻动作。切换动作保留各自未提交的范围草稿。去除背景与生成图集是两个输出选项，裁切、抠像和尺寸参数默认折叠，不再显示重复的抽帧开关。底部「应用并处理」根据实际产物计划必要步骤：改变时间、FPS、裁切重新抽帧；只改抠像参数重新抠图；只改单格尺寸重新合成。执行前简短显示步骤和动作数量，应用本轮全部草稿，未改变的动作范围保留；新结果保存新版本，原视频与旧版本保留。「更多处理」提供强制重新抠图或合成，若上游范围已修改仍先补齐抽帧；仅视频任务未完成或异常时显示查询任务。这里全部是本地处理，不调用生成或清晰化模型。
   抽帧保留原视频细节再按四列两行切分，单格内容上限 432×480；768P 不先降至 480P。抠图先从真实视频格内采样背景、修复混色边缘，再放入透明的 512×512 画布，避免纯色补边干扰背景判断。重新抠图保留原始帧与旧版，原 MP4 不改变；透明结果为独立 PNG 序列帧和素材包版本。导出元数据记录实际源视频尺寸，放大不能补回视频丢失的细节。
5. **高清重绘（可选）**：重绘方案与范围分开选择，提供「4 帧一张」「8 帧一张」和「逐帧重绘」。同动作、同方向的时间采样帧按 2×2 或 4×2 拼图，通过一次 `images/edits` 重绘再拆格；不跨动作或朝向，按源索引排序。范围支持当前方向、八方向与手动选帧，动作可选择单个或全部；选项分两排显示，自动模式按方案/帧数、动作/范围排列，手动模式按方案/范围、动作/方向排列。八帧拼图仅提供每方向 8/16/24 帧，四帧拼图和逐帧方案提供 4/8/12/16/20/24 帧，切换八帧方案时向上调整到可用档位。按动作与方向分组，在所选完整时间范围均匀取样，保留原时长，例如 24 帧取 8 帧使用第 1、4、7、10、13、16、19、22 帧；少帧仍可能遗漏快速动作细节，实际动作范围须先校准；手动选帧展示原视频的全部源帧（默认 2 秒 × 24 FPS = 每方向 48 帧），不受自动清晰化帧数限制，提供动作和方向筛选及选择/清除可见帧；重绘方案仍决定勾选帧如何分组调用。客户端核对后台返回方案，不一致或缺失时阻止提交并提示完全退出 DSH（包括托盘）后重启。取消 24 帧下限，删除试组按钮。24 个连续帧按四帧/八帧方案分别需要 6/3 次调用。已完成帧默认跳过，任意非空小范围或剩余帧均可继续处理；不复制或补出不存在的帧。固定修复规则只动态填入方向、角色说明、本轮要求和背景色，不再调用文字模型改写。使用全局自定义 OpenAI 兼容后端，发送拼图、角色图、对应方向外观（如有）和遮罩；四帧请求 2048×2048、八帧请求 4096×2048，逐帧请求 1024×1024，服务商须支持对应尺寸。尾组按实际帧数使用 1×1、2×2 或 4×2，空格保持背景和锁定遮罩。回图比例须匹配布局且每格至少 512px，所有有效格有主体才整组完成，最终每帧 512×512。保留原帧、原始回图、输入、遮罩、提示词和校正记录；同组帧共享调用 ID。`planOnly:true` 使用同一规划器只读计算帧数和新增调用，不改任务、不收费。未知请求须显式重新生成。48 帧行走 + 41 帧奔跑 × 八方向共 712 帧，四帧/八帧/逐帧方案分别需要 184/96/712 次调用。**更少调用不保证更低费用；模型仍可能改变布局、姿势或颜色，需验收动画一致性；尺寸和空格检查不能保证语义布局正确。**
6. **预览与导出**：结果直接循环播放，无需展开；可切换动作、方向，暂停逐帧检查和调整播放速度。完整八方向结果还支持同时预览与 WASD/方向键试玩；试玩需先点击画面获取焦点，停止移动时停在首帧，不自动合成待机动作。各版本按当时保存的时长与帧数播放。时间与文字式执行详情在画面上方，版本与播放筛选在底部同排。下载统一为一个菜单，包含当前帧和各次素材包，包的来源与版本分别标识，不替换预览。每种动作导出透明序列帧和方向图集；图集按 4096×4096 上限自动分页，一并打入 ZIP，附 `animation.json`、视频提示词与白模来源许可。本次所选高清帧完成后自动执行本地合图与高清导出；只包含本次范围，按实际帧数在完整动作时长内播放。失败会保留本批已成功帧，结果未知的请求不自动重试。高清版要求本次范围全部帧已完成，以免混入清晰度不同的帧。元数据记录各方向实际帧数、帧率、源索引和时间；原帧版本不受影响。本地抽帧与抠图不算 AI 清晰化，新导出版本保存 raw/keyed/redraw 来源，旧包没有来源时不猜测。循环接缝需人工验收，元数据标为 `loopVerified:false`。

`animation.json` 使用 `version:2`：动作包含 `fps`、`frameDurationMs` 和 `sheets` 数组。每页记录 `file`、`firstFrame`（从 0 开始）、`frameCount`、`rowOrder`、`columns`、`rows`，方向行与帧列可分别分页。单页时仍保留兼容字段 `sheet`；多页时应读取 `sheets`。例如默认 512×512 单格、每方向 48 帧，会导出 6 张 4096×4096 图集，每页包含八方向各 8 帧。

高清回图存在真实透明背景时保留原始 alpha，不再按透明像素的黑色 RGB 二次抠图；不透明底色仍走原抠像流程。同一次回图的所有格共用人物比例校正，以各自原视频帧的上半身位置对齐，保留原动作起伏，不逐帧强行撑满画布。比例、姿势或位置偏差过大时整组停止并保留原始回图，不自动重新调用；记录背景处理方式、缩放比例与位移。此校正不能修复模型改变的动作或外观。

AI 清晰化弹窗的选项按两列两排显示：自动模式第一排为重绘方案、每方向帧数，第二排为选择动作、处理范围；手动模式第一排为方案、范围，第二排为动作、方向筛选。动作列表来自本轮全部源帧，支持「全部动作」，按每个动作、每个方向独立均匀取帧和分组计费，已有成功帧默认跳过。预览只包含一个动作的高清版时，仍可选择其他源动作。打开时选中当前预览动作，切换动作仅更新计划与调用数量，不提交生成、不改变预览；手动选帧继续保留自己的勾选和筛选。

单方向播放时，右上角「开始帧」直接暂停并保存当前实际显示的帧，在右上角固定显示该帧缩略图；继续逐帧对比后点「结束帧」确定包含两端的有效范围，× 清除范围与缩略图。范围按本轮子任务、动作和方向保存，切换版本后沿用源帧索引，稀疏高清版本缺少该帧时使用原始抠图帧预览。范围外帧在手动选帧里禁用，自动采样、清晰化数量、调用计划及高清导出均排除。保存失败显示错误，不显示虚假的成功预览；后台未更新并丢弃字段时提示重启。聊天右侧的 1、2 等数字仍是独立的轮次跳转入口。

选择「视频抽帧」「抠图帧」或「AI高清帧」后，可在结果版本下拉菜单底部点击「删除当前版本」。确认弹窗写明所选版本，确认后删除该版的全部帧文件，自动切到保留的同类版本；其他版本、素材包和生成视频保留，处理中的轮次禁止删除。视频没有删除入口，后台也拒绝删除视频。版本编号保持原编号，新版本接着递增。内部处理源帧与付费记录保留，以便继续抽帧、抠图或处理剩余帧；删除历史结果不会自动再次调用模型。

## 配置与成本

- 输入栏首位的「审核模式」支持自动和人工。自动按处理配置继续抽帧与合成；人工生成后停在视频，解析已有视频则抽帧后暂停合成，通过本轮「视频处理」继续。关闭提取配置时仍保留视频，不自动抽帧。
- 输入栏同一个分组菜单分别选择视频模型与 DSH 提示词模型，同时显示两个当前型号；视频选择只影响当前任务。连接与 Key 沿用视频设置；只列支持 4 秒参考视频的型号，H3-Lite 使用 480P，H3 与优云智算 H3 使用 768P。H3-Max、Hailuo 等不满足当前时长的型号不列入；ComfyUI / ToAPIs 仍用于原有流程。每次费用确认显示实际型号和分辨率，提交时保存模型、网关与分辨率快照，切换配置不改变已排队轮次。
- 解析视频只上传已有视频，不上传动作素材，不调用视频或提示词模型。无需选择动作或确认分段，新导入默认按完整视频与 24 FPS 计算抽帧数量（每帧裁成八个方向）；处理配置支持调整起止时间与目标 FPS，单段超过 720 帧时需调整后继续。解析范围独立保存，切回生成时保留原动作草稿，目前不自动识别视频动作。
- 目标 FPS 控制采样与播放节奏，不是 AI 运动补帧。目标高于源视频帧率时可能重复原帧，不会创造新动作；AI 高清重绘也不等于时序超分或插帧。
- 图片使用全局「自定义生图 → OpenAI 兼容」配置。中转必须支持多图与遮罩的 `images/edits`。不支持时直接报错，不自动改走无动作约束的 `generations`，也不自动重试。
- 文字模型配置和估算单价位于「处理配置 → 文字模型与费用设置」。默认本地地址 `http://127.0.0.1:11434/v1`，无需文字模型也能使用模板。
- 视频估算按 **4 秒输入 + 4 秒输出** 计算，默认 ¥0.16/秒只是此前试验使用的参考值，可修改，**不是实时平台报价**。图片单价默认 0 表示未知。以服务商账单为准；第三方文字模型也可能计费。
- 白模拼接、裁切、抠像、图集和 ZIP 导出在本地完成。480P 八格中的每个角色只有约 216×240 的画面；512×512 是输出画布尺寸，局部放大不会创造原生细节。

## 任务与恢复

- 数据放在 `<DSH_HOME>/game-material-master/motion-jobs/w…/`，文字模型设置在相邻的 `motion-settings.json`，凭据只在本机保存且不回传界面或 agent。
- 每个任务同一时间只执行一个步骤。视频提交前落盘记录；提交结果未知时锁住再次生成，避免网络中断导致重复扣费。可导入已获取的视频继续。
- 每帧重绘前保存尝试记录；结果未知的帧不会自动重试，须用户明确勾选重新生成。成功回图在后处理失败时也保留。
- DSH 重启后只查询和下载已经提交的视频，不自动重新提交收费步骤。中断的本地步骤保留已有文件，可手动重做。
- 「停止后续处理」在本地处理边界生效。已经提交的远端请求可能继续完成并计费，不代表退款或远端取消。
- 后台刷新使用草稿合并，保留用户尚未保存的提示词和分段编辑。

`verify-motion.mjs`、`verify-motion-redraw.mjs` 与 `verify-workflow-chat.mjs` 使用临时 DSH_HOME、本机假 API 和真实 ffmpeg，拦截非测试服务的网络请求，不花 API 费用。分组测试校验 712→184 的请求数、真实四格拆分顺序与透明像素、共享调用记录、失败阻断、空格和错误尺寸拒绝及显式重试。需要 `ffmpeg` 与 `ffprobe`，可通过 `FFMPEG_PATH` / `FFPROBE_PATH` 指定。`verify-workflow-browser.mjs`、`verify-motion-preview-browser.mjs` 与 `verify-motion-playback-browser.mjs` 使用真实 Chromium 验证上传、草稿复用、动作播放、重绘方案/范围、计费确认、紧凑菜单、浅深主题及大小窗口布局。构建后需完全退出 DSH（包括托盘）再重开；模拟验证不代表真实模型质量通过验收。

内置模板来自 [Hormelz 八方向近战角色](https://hormelz.itch.io/8-directional-melee-character)，CC0-1.0。原始动作关键帧、画布与时间信息以 gzip RGBA 保存，运行时无需 Python。开发导入脚本为 `scripts/import-motion-templates.py`，导入时需要 Pillow。插件代码沿用原仓库 MIT 许可；模型生成素材的使用权仍由对应服务条款与输入素材授权决定。

聊天初次进入或发送新一轮时直接定位到底部，不播放从顶部滚动到底部的动画。停留底部时，图片、视频晚加载与窗口尺寸变化继续跟随；主动上翻或使用轮次定位后保留阅读位置，切回聊天立即恢复。

图片选帧只在本地生成小尺寸预览并缓存，不改变已抽帧结果、处理参数或原视频，不调用 AI。点击缩略图会暂停视频并切换当前预览，不改变起止范围；对应缩略图左上角显示「开始帧」「结束帧」，修改范围时同步移动标记。视频按原始比例铺满预览宽度，高度不再固定限制为 200px；设置在弹窗内滚动。视频右上角只保留「帧对比」按钮，图标与文字居中；开始帧在独立对比弹窗内查看。预览失败可手动重试，旧请求不会覆盖新滚动位置；弹窗高度受视口限制，关闭及应用按钮保持可见。

点击视频右上角的「帧对比」，可打开独立对比弹窗。宽屏左右显示开始帧与当前帧，窄屏上下显示；直接从原视频解码完整分辨率画面，按窗口大小等比显示，移除底部缩放工具。动作选择、逐帧/范围播放与暂停、图片选帧、帧号定位、起止手柄、起止帧和抽帧 FPS 全部集中在对比弹窗，外层只保留视频预览及处理配置。暂停定位时忽略与实际视频位置不符的迟到帧回调，防止刚选的当前帧跳回旧画面。

每个动作检查后分别点击「确认当前动作」，底部显示已确认数量。全部动作确认后，外层「应用并处理」才可用；单动作解析仅需确认这一段。浏览其他帧、切换动作或关闭对比弹窗保留确认，修改起止范围或抽帧 FPS 后仅取消该动作的确认，改回旧值也需重新确认。播放中、画面未加载或读取失败时不可确认。关闭或按 Esc 返回原处理弹窗，保留本次草稿和确认；重新进入视频处理需重新检查。确认本身不处理、不调用模型；只有外层「应用并处理」才执行本地处理。
